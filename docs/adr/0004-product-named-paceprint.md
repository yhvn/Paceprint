# The product is named Paceprint, not Paceline

The design and early planning call the app "Paceline", but two Health & Fitness apps already use that name on the App Store, one of them a run tracker ("Paceline: Run & Ride Tracker"), so we'd face a crowded listing and trademark risk. The repo's spelling "Peacline" was a typo, not a brand. We renamed to **Paceprint** (pace + print: each Run becomes a print-like card) while the Xcode project was still an empty template; a US App Store search found no app with that name (not a trademark search). The bundle ID is `com.yhlabs.paceprint`, which can never change once shipped.

## Considered Options

- **Keep "Paceline" with a distinguishing store name**: allowed, but sits beside a same-named run tracker.
- **"Peacline" as a coined name**: reads as a misspelling.
- Other free candidates were Runprint, Pacetrail, Runglow, Pacecard.
